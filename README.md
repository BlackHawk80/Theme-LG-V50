# AURA GLASS Android Launcher

Giao diện Home Liquid Glass cho Android, không root, build bằng GitHub Actions. Mở tab Actions → Build installable Android APK → Artifacts để tải file APK. Thử nghiệm trên điện thoại trước khi dùng làm Home mặc định.

- Android 8.0+ (ưu tiên Android 12 / LG V50)
- Mở ứng dụng đã cài, Dock 4 ứng dụng, tìm kiếm, Light/Dark, đồng hồ/ngày/pin.
- Dùng Home settings để khôi phục launcher gốc nếu cần.
- Không phải system theme; không thay Control Center/lockscreen.
